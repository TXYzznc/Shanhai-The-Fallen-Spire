# 美术资源技术规范

本规范只描述入库和运行时技术约束，不定义题材、角色、场景或视觉内容。

## 交付信息

每项资源必须声明：

- 文件格式和色彩空间；
- 尺寸、透明度与通道用途；
- pivot、网格、边距或切片规则；
- 目标平台与压缩策略；
- 导入设置和运行时用途；
- 来源、许可和可修改范围。

## 2D

- 避免无意义透明边界。
- 图集必须记录 padding、extrude、旋转和裁切策略。
- 像素资源使用与目标一致的过滤方式。
- 法线、遮罩和其它辅助纹理必须在名称或索引中声明用途。

## 3D

- 坐标系、单位、朝向和缩放必须统一。
- 模型必须声明拓扑、UV、材质槽、LOD、碰撞和骨骼约束。
- 导出前清理隐藏对象、无效材质、重复网格和未使用数据。

## UI 与字体

- UI 资源必须声明九宫格、状态变体、最小尺寸和安全区约束。
- 字体必须记录许可、字符覆盖、fallback、atlas 生成参数和裁剪策略。
- 不在框架基线提交页面效果图、内容图集或预生成文本样例。

## 验收

- Unity 导入无错误；
- 引用完整且无重复 GUID；
- 压缩和内存预算满足目标平台配置；
- 资源在目标材质、渲染管线或 UI 系统中行为一致；
- 源文件与生成物边界清晰。
