# 资源配置规范

本规范只定义领域无关的资源约束。具体项目必须自行声明资源类型、目录、
命名、索引和生命周期。

## 原则

- 资源路径和标识由配置提供，不在代码、agent 或 SKILL 中硬编码。
- 目录按技术用途组织，不按具体内容模型预建目录。
- 文件名使用稳定的 ASCII 标识；展示名称通过本地化或配置提供。
- Unity 资产移动、重命名和删除必须同时维护 `.meta` 与 GUID 引用。
- 可再生输出与源资源分离；包含具体项目输入的输出不进入框架基线。
- 导入设置必须显式声明目标平台、压缩、色彩空间、mipmap、读写和尺寸上限。

## 索引契约

资源索引格式由具体项目选择，但至少包含：

- 稳定 ID；
- 资源类型；
- 可配置的加载定位信息；
- 生命周期或释放策略；
- 可选的平台和变体条件。

框架只提供读取和校验边界，不定义具体项目的 ID 段、目录或内容字段。

## 验证

- 索引引用的资源必须存在；
- GUID 不得悬空或重复；
- 大小写必须与磁盘一致；
- 平台变体必须有确定回退；
- 未引用资产是否删除由具体项目策略决定，框架基线不保留样例资产。
