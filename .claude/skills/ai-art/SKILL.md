# AI 美术生产

## 输入

先从当前任务、项目配置和用户提供的参考资料中提取：

- 产物用途和目标文件路径
- 尺寸、比例、透明度、色彩空间和格式
- 视觉风格、构图、视角、光照和材质约束
- 必须保留与必须排除的元素
- Unity 导入、切图、命名和压缩要求

缺少会改变产物方向的约束时先提问。不得用内置题材或历史项目内容补齐空白。

## 执行

1. 将输入整理为主体、环境、构图、风格、技术规格和排除项。
2. 选择当前会话可用的图像生成或编辑工具。
3. 编辑已有图像前先检查目标图；新建图像时只使用本次任务提供的约束。
4. 生成后检查尺寸、透明区域、边缘、构图、可读性和明显伪影。
5. 需要工程化处理时，按任务指定路径完成切图、命名和导入设置。
6. 记录实际输出、检查结果和未满足的约束。

## 参考图反推

仅在需要从现有图像提炼提示词时读取
[`references/image-to-prompt-generator.md`](references/image-to-prompt-generator.md)。

## 边界

- 不保存项目专属美术设定到本 SKILL。
- 不提供内置角色、场景、界面、图标或题材模板。
- 不把示例资源写入框架目录。
- 不猜测品牌色、世界观、玩法语义或资源标识。
- UI 结构由任务指定的 UI 工作流确定；本 SKILL 只处理图像产物。
