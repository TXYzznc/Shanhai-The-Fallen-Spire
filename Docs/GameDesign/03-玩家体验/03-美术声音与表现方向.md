# 美术、声音与表现方向

> 状态：部分确认，资源交付边界待确认

## 美术方向

- 二次元角色正比立绘、Q版角色和武器作为整体方向参考。
- Demo地图为明亮、神秘的森林环境。
- 角色和敌人使用四方向表现，具体资源格式由美术需求确认。
- 角色为近战长剑、蒙面、绷带、无法直接判断性别的人类形象。

## Demo资源清单

- 玩家角色：站立、移动、普攻、技能、大招、受击、死亡等动作。
- 普通敌人：站立、移动、攻击、受击、死亡。
- 精英敌人：基础动作和专属技能表现。
- Boss：基础动作、攻击模组、技能和死亡表现。
- 地图底图、墙壁碰撞、树木、灌木、植物、水池、岩石和雕像。
- 3个兽印图标、增益图标、技能图标。
- 命中、闪避、失衡、技能、掉落和开门特效。
