# 视角、交互与信息呈现

> 状态：部分确认

## 交互输入

- PC为目标平台。
- WASD移动，鼠标控制攻击方向。
- 手柄左摇杆移动、右摇杆控制攻击方向作为输入扩展。
- 大部分攻击允许移动。
- 兽印和增益通过选择界面确认。
- 兽印奖励只获得兽印；HUD按钮或Tab打开装配界面，玩家手动装配、卸下和替换。Tab切换开关，Esc或关闭按钮关闭。

## 战斗HUD

需求表确认战斗HUD需要显示：

- 生命条。
- 技能状态。
- 兽印槽位。
- 右上角普攻、技能、大招、属性四槽，空槽或对应兽印图标；旁边提供“兽印装配 [Tab]”按钮。
- 经验或升级状态。
- 必要的战斗状态提示。

伤害数字、能量条、失衡条、掉落提示和敌人血条是否显示，仍需确认。

## 界面范围

- 从Launch进入标题/开始游戏/退出界面，再开始本局。
- 需要战斗HUD。
- 需要兽印界面，显示位置、功能、装备后的效果和属性变化。
- 兽印装配界面包含已拥有列表、四槽区、效果详情及操作按钮，详情见[兽印装配界面](../02-系统设计/07-兽印装配界面.md)。
- 需要增益三选一界面。
- 装配及兽印/增益三选一打开时暂停战斗，通过通用管理器登记界面暂停计数，全部暂停请求释放后才继续；界面输入不受战斗暂停影响。
- 不制作独立胜利/失败界面。
- 返回、重试和复活流程需要明确按钮或输入方式。
