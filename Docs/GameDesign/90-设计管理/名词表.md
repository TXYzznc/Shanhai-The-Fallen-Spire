# Demo名词表

| 名词 | 定义 |
|---|---|
| Demo | 本次交付的最小可玩版本，包含1角色、1地图、1普通敌人、1精英敌人、1Boss和3个兽印。 |
| 兽印 | 可装备到槽位并改变角色攻击或属性的构筑内容。 |
| 已拥有兽印 | 本局已获得并保留的兽印集合，卸下或替换不失去，重试清空。 |
| 兽印装配界面 | 玩家手动装配、卸下或替换已拥有兽印的界面，打开时暂停战斗。 |
| 普攻槽 | 影响角色普通攻击的兽印槽位。 |
| 技能槽 | 影响主动技能的兽印槽位。 |
| 大招槽 | 影响大招或终结技的兽印槽位。 |
| 属性槽 | 影响角色基础属性的兽印槽位。 |
| 增益 | 通过选择获得的局内成长效果，可以是数值、攻击、技能或规则变化。 |
| 失衡 | 玩家在限定时间内对目标造成足够伤害后触发的倒地状态；失衡期间目标受到更高伤害。具体阈值和持续时间待确认。 |
| 硬直 | 角色或敌人受到攻击后短时间无法正常行动的受击状态。 |
| 检查点 | Demo地图中用于升级和记录推进阶段的位置。 |
| 索敌范围 | 敌人能够发现并触发战斗的范围。 |
| 一波敌人 | 当前Demo中一次触发的敌人群体，具体数量待确认。 |
| 三选一 | 展示三个奖励或兽印选项，玩家确认其中一个。 |
| 兽印替换 | 将已装备的兽印换成另一个兽印；替换后旧效果立即消失。 |
