# 敌人与Boss

> 状态：待补齐

## Demo数量

- 普通敌人1种。
- 精英敌人1种。
- Boss1个。

## 普通敌人

需要甲方提供：生命、攻击、移动速度、索敌范围、攻击方式、攻击前摇、攻击后摇、受击表现、死亡表现和掉落。

## 精英敌人

需要甲方提供：独立技能、技能范围、预警、前摇、冷却、受击规则、失衡规则、死亡掉落和开门条件。Demo中精英敌人固定触发兽印三选一。

## Boss

需要甲方提供：技能清单、攻击模组、预警、技能冷却、阶段变化、召唤规则、场地变化、受击规则、死亡表现和掉落。Demo不制作Boss剧情。

## 刷怪规则

- 敌人在地图若干位置随机刷新。
- 普通敌人群聚在一定范围内。
- 玩家进入敌人索敌范围后触发战斗。
- 当前确认只有一个波次。
- 普通敌人、精英敌人和Boss的具体数量与摆放仍需地图表确认。

## 当前Demo敌人状态显示

普通、精英和Boss头顶显示当前生命/最大生命与血条。失衡可用时显示蓝色积累条；积累窗口到期后归零，失衡发生后显示剩余恢复进度。精英与Boss蓄力时显示黄色蓄力进度；硬直、冲撞及Boss二阶段使用文字提示。没有对应状态时不显示该项。

显示读取既有生命、失衡和AI计时，不改变伤害、阈值或行为。UI来自Assets/Game/Prefabs/UI/Item/DemoEnemyStatus.prefab，绑定当前HUD与相机；死亡、离屏或实体隐藏后不可见，重试/复用按本局重新绑定。UI不拦截鼠标射线，正式视觉素材仍待后续替换。
