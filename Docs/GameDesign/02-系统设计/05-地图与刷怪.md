# 地图与刷怪

> 状态：部分确认

## 地图范围

- 1张线性地图。
- 玩家从下往上推进。
- 允许回头。
- 包含1个Boss房间和1个检查点。
- 击败精英敌人后开门。

## 场景元素

根据Demo美术素材需求，地图需要底图、墙壁碰撞、小景物、灌木、树木、奇特植物、水池、岩石和受侵蚀的神秘雕像。哪些资源需要原创制作、哪些由甲方提供，需要在资源清单中确认。

## 刷怪与推进

- 敌人分布在地图若干位置。
- 进入索敌范围触发战斗。
- 当前只有一个波次。
- 精英战斗完成后开放道路。
- 检查点用于升级。
- Boss战完成后进入Demo结束流程。

## 待确认

- 地图长度、宽度和分段数量。
- 普通敌人和精英敌人的刷新坐标。
- Boss房间是否封锁出口。
- 检查点是自动触发还是交互触发。
- 玩家是否可以在战斗中离开索敌范围并脱战。
