## 增益分类

| 类型 | 需要补齐的内容 |
|---|---|
| 数值型增益 | 生命、攻击、防御、移速、技能冷却等具体数值 |
| 攻击变化增益 | 攻击方式、弹道、攻击范围、攻击次数或攻击属性 |
| 技能变化增益 | 技能或大招的机制、范围、伤害、冷却和资源规则 |
| 特殊规则增益 | 召唤、反伤、特殊状态、风险收益或规则改变 |

## 必须明确

- 每类增益各有多少条。
- 一局预计出现多少次增益选择。
- 增益是否可以重复获得、叠加或升级。
- 同类增益是否互斥。
- 增益如何进入随机池及出现权重。
- 升级是只发生在检查点，还是战斗中也会触发。
