# 兽印装配界面

> 状态：功能规则已确认，代码与预制体已接入，20项自动测试通过；实机待用户验收。2026-10-07完成三轮决策；开发侧已获授权决定待定部分，重复兑换暂定100货币，图标使用可替换临时Sprite，详见[暂定参数](../未确认暂定内容/07-兽印装配与暂停暂定参数.md)。

## 已确认流程

- 三选一奖励界面只选择并获得一个兽印，不选择目标槽位，不直接改变装备。
- 本局获得的兽印保存在“已拥有兽印”列表中。
- 玩家在兽印装配界面自由装配、卸下和替换，换下的兽印仍保留在列表中。
- 任意兽印可放入普攻、技能、大招、属性槽位；同一个兽印不能同时占用多个槽位。
- 更换后旧效果立即消失，新效果生效；重新开始一局清空已拥有兽印和四槽装备。
- DemoHud右上角按固定顺序显示普攻、技能、大招、属性四个槽位，状态只有空槽或已装配某个兽印，后者显示该兽印对应图标。
- HUD提供兽印装配按钮，Tab可快速打开装配界面。
- 打开装配界面时暂停战斗，包括敌人行动、伤害和冷却计时，关闭后继续。
- Tab切换开关，Esc或关闭按钮关闭；奖励和结算界面显示期间禁止打开装配界面。
- 三选一仍展示已拥有兽印；再次选择已拥有兽印转为货币，不新增副本、不升级、不自动装配。
- 三选一奖励界面打开时也暂停战斗，包括兽印与增益两种奖励。
- 已拥有兽印及装备在本局首次复活时保留；重试或开始新一局清空。

## 界面组成

界面是HUD之上的居中弹窗，底层遮罩阻挡对战斗世界与HUD的点击。

| 区域 | 功能与内容 |
|---|---|
| 标题栏 | “兽印装配”、已拥有数量、关闭按钮，并提示“Tab / Esc 关闭” |
| 左侧：已拥有兽印 | 图标、名称、当前装配位置；点击选中。仅展示本局已获得的兽印，不显示未获得兽印为可装配项 |
| 中部：四个槽位 | 固定显示普攻、技能、大招、属性；空槽显示空槽底图和“空”，已装配显示对应图标与名称；点击选中目标槽 |
| 右侧：详情与操作 | 选中兽印名称、图标、四槽效果说明，重点显示目标槽的效果；当前目标槽装备、操作提示、“装配 / 替换 / 移动”及“卸下”按钮 |
| 底部提示 | “兽印只在本局保留，卸下不会失去兽印”；操作成功显示结果，失败说明原因 |

已拥有列表为空时显示“尚未获得兽印，击败精英敌人或Boss可获得”，四槽仍可查看，装配与卸下按钮禁用。已装配的兽印仍显示在列表中，标明“已装配：技能”等位置，不移出列表。

## 点击式装配流程

1. 玩家点击左侧一个已拥有兽印，再点击目标槽位；也允许先选槽位再选兽印。
2. 详情区展示本次操作的结果，选中与预览本身不改变装备。
3. 点击操作按钮提交一次装备变更，效果与HUD立即同步；不需要关闭界面或另按全局“保存”。
4. 目标槽为空时按钮显示“装配”；非空时显示“替换：原兽印名”，原兽印保留在已拥有列表。
5. 选中兽印已在其他槽位时按钮显示“移动：原槽 → 目标槽”，原槽清空；目标槽原兽印回到未装配状态，仍在已拥有列表。移动作为一次完整变更提交。
6. 选中兽印已在目标槽时显示“已装配”，按钮禁用，避免无意义重复操作。
7. 选中非空槽时可点击“卸下”，仅清空该槽并移除其效果；兽印仍保留，空槽的卸下按钮禁用。
8. 关闭只结束查看和操作，已提交的变更保留；未提交的选中状态丢弃。再次打开读取当前实际装备。

Demo采用点击操作，不要求拖拽、批量方案、自动推荐或额外确认弹窗。明确的操作按钮和操作前预览提供替换反馈。

## HUD右上角

- 从左到右为普攻、技能、大招、属性，显示槽位标签及图标。
- 空槽只显示统一空槽底图；已装配槽只显示所装备兽印的对应图标，不在HUD堆叠详细说明。
- 悬停可显示兽印名称与该槽效果，属于详情提示，不增加第三种槽位状态。
- 四槽旁设置“兽印装配 [Tab]”按钮；Tab与按钮打开同一个界面。
- 奖励或结算界面显示时按钮禁用，Tab不打开装配界面；装配界面显示时Tab关闭。
- HUD与装配界面使用同一份实际装备数据，不各自保存一套装备状态。
- 原HUD的四槽长篇效果信息收进装配界面的详情区，右上角保留紧凑的状态显示。

## 三选一奖励调整

- 删除目标槽选择和直接装备逻辑，奖励卡显示名称、图标与效果说明。
- 未拥有选项显示“获得兽印”；已拥有选项显示“已拥有，重复选择获得 X 货币”，确认操作说明与实际奖励一致。
- 首次获得只加入已拥有列表，四槽装备保持不变；提示“已获得兽印，可按Tab装配”，不自动打开装配界面。
- 重复选择只发放配置中的兑换货币，已拥有列表与装备保持不变；提示获得的货币数量。
- 重复兑换数额使用单独的正整数配置，Demo暂用100，正式平衡数额待确认；不从名称、等级或Boss货币掉落量推导。
- 沿用奖励选择的现有两次点击确认流程，一次奖励只允许领取一次，不因双击多次发放。
- 普通增益三选一沿用现有获得后生效的流程，本次“获取与装配分离”仅针对兽印。

## 暂停、互斥和生命周期

- 装配界面暂停角色移动、攻击、闪避、敌人行动、伤害、物理模拟和战斗计时；界面按钮与Tab / Esc在暂停时仍工作。
- 通用游戏状态管理器统一管理暂停计数；装配、兽印奖励、增益奖励界面均注册为可暂停界面，打开时自动登记、关闭时自动释放。
- 计数表示当前持有暂停请求的界面数量，而不是注册的界面总数；只有计数为零才允许继续。一个界面重复打开不重复加一，重复关闭不重复减一。
- 例如界面A与B都打开时计数为2，关闭A后仍为1且保持暂停，关闭B后为0才恢复；这一规则适用于后续注册的界面，不只适用于兽印界面。
- 打开装配界面前进行奖励、结算、重试状态检查；防止本界面重复打开及重复登记暂停。
- 最后一个暂停请求释放后恢复首个请求前的战斗速度；界面关闭只释放自身请求，不直接写“恢复游戏”。其他系统需要暂停时也使用同一管理器。
- 关闭按钮的鼠标点击不能同时触发角色普攻，Tab关闭也不能造成残留战斗输入。
- HUD关闭、玩家解绑、切换场景、重试或异常销毁时关闭装配界面并释放其暂停，避免新场景永久停住。
- 奖励卡确认成功并隐藏、无可用奖励、HUD退出、界面销毁或解绑时同样对称释放奖励界面的暂停；登记监听随界面生命周期注销。
- 首次复活保留兽印所有权和装备；重试清空后更新列表、四槽和奖励状态。

## 验收边界

- 获得奖励后已拥有列表增加，四槽装备保持原样。
- 装配、卸下及替换后，HUD对应槽位状态与实际装备一致。
- 只能装配已拥有的兽印，同一兽印不能同时占用多个槽位。
- 换下的兽印仍可重新装配；重试后列表与四槽均清空。
- 跨槽移动同时处理原槽和目标槽，只公布最终装备状态，不通过中间空槽产生额外生命调整。
- 重复奖励仅兑换一次货币，不改变拥有集合和四槽；奖励界面不再出现槽位按钮。
- HUD四槽图标、空槽状态、按钮与Tab入口均可用，打开关闭及模态互斥符合上述规则。
- 装配期间战斗与冷却计时停止，UI仍能操作；正常关闭、重试、场景退出和销毁均不会留下暂停。
- 兽印或增益三选一打开期间战斗停止；两个可暂停界面同时登记时，只关闭其中一个不能恢复战斗。
- 重复打开、重复关闭、未打开即注销及已打开界面异常销毁不会造成计数错误或负值。
- 自动验证使用单元测试与程序集编译，覆盖所有权、替换移动、重复兑换、输入与暂停释放；实机测试由用户运行，不控制电脑。
- 2026-10-07追加确认：装配、奖励与结算拆成独立GF.UI窗口，按需加载及框架回收；常驻HUD按生命/能量/技能、局内信息、四槽摘要拆成独立功能区，表现层独立。输入与互斥由会话协调器持有，保持上述玩法与操作规则。
