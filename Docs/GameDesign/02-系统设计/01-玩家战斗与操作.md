# 玩家战斗与操作

> 状态：部分确认

## 操作

| 功能 | 当前确认 |
|---|---|
| 移动 | WASD或手柄左摇杆 |
| 攻击方向 | 鼠标或手柄右摇杆 |
| 普攻 | 2段攻击，大部分攻击允许移动 |
| 闪避 | 0.2秒内连续移动2米，起步锁定方向，遇障碍停止；移动中和攻击中均可触发，具有无敌帧 |
| 主动技能 | 1个，朝面向方向释放扇形重攻击 |
| 大招 | 1个，能量随时间缓慢恢复，满能量后主动释放 |

## 战斗状态

2026-10-07用户追加确认：移动和攻击过程中可以闪避，闪避具有无敌帧，替代旧版“攻击期间禁止闪避”限制。普攻打断与同帧优先级的开发侧处理见[玩家战斗暂定数值](../未确认暂定内容/01-玩家战斗暂定数值.md)；具体时长仍待正式数值确认。

2026-10-08用户确认连续冲刺替代瞬移，持续0.2秒、距离2米；闪避期间不叠加普通移动，暂停时冻结剩余位移，重试时丢弃剩余位移。原冷却、无敌与攻击取消规则保留。

- 受击后触发硬直。
- 在限定时间内受到足够伤害后触发失衡。
- 失衡是《渡山海.docx》中明确提出的战斗概念，原文同时写明失衡表现为摔倒且失衡状态下受到的伤害增加。
- 一局最多使用1次复活；复活后再次死亡则重新开始。
