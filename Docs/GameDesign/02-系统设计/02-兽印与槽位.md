# 兽印与槽位

> 状态：部分确认，3个兽印的具体效果未完成

## 数量

- Demo包含3个兽印。
- 每次兽印奖励展示3个选项，玩家选择其中1个。
- 精英敌人Demo中固定掉落一次兽印选择。
- Boss固定掉落一次兽印选择。

## 四个槽位

需求表已确认四个槽位为：

1. 普攻槽
2. 技能槽
3. 大招槽
4. 属性槽

三个兽印可以放入任意槽位，但同一个兽印不能同时占用多个槽位。属性效果优先于机制效果；更换兽印后旧效果立即消失。

## 获得与装配（2026-10-07补充确认）

兽印可随时更换。三选一奖励只获得兽印，不直接装备；本局获得的兽印保存在已拥有列表中，玩家通过兽印装配界面自由装配、卸下、替换，换下的兽印仍保留。首次复活保留，重试清空。重复选择已拥有兽印转为货币，兑换数额待定。

HUD右上角显示四槽空槽或已装配图标，HUD按钮和Tab打开装配界面；装配期间暂停战斗。完整交互与验收见[兽印装配界面](07-兽印装配界面.md)。代码与预制体已接入并通过自动测试，实机待用户验收；旧Windows Player尚未包含本批功能。

## 每个兽印必须补齐

- 名称与定位。
- 图标和颜色。
- 可放入的槽位。
- 放入普攻槽时的效果。
- 放入技能槽时的效果。
- 放入大招槽时的效果。
- 放入属性槽时的效果。
- 触发条件、具体数值、持续时间、冷却和叠加规则。
- 三选一界面的描述文字和确认反馈。

当前只确定了槽位类型和装备关系，3个兽印的具体效果不能由本文件代填。
