# 兽印装配与暂停暂定参数

> 2026-10-07：用户授权开发侧自行决定本批待定部分并在此归档。以下是实现参数，不代表正式平衡或正式美术确认。

## 重复兽印兑换

- 三选一保持三个兽印选项，不排除已拥有的兽印。
- 重复选择兑换100货币，每次奖励只发放一次；不增加副本、不升级、不自动改装备。
- 数额通过DemoGameplayConfig.duplicateMarkCurrency配置，要求正整数。奖励卡、悬停说明和获得提示读取同一配置值。
- 100仅用于Demo流程验证，正式数额由后续经济平衡决定。

## 图标与布局

- 裂锋使用橙色斩痕图标，镇岳使用蓝色山峰图标，逐影使用紫色双翼/速度线图标。
- 三个图标为64×64临时Sprite，保存在Assets/Game/Sprites/Demo；配置直接引用同一Sprite，奖励卡、列表、装配槽和HUD共用。
- 使用可替换的几何占位素材，后续替换Sprite引用不影响装配和奖励逻辑，不作为正式美术交付。
- 装配弹窗参考布局1040×670，左侧已拥有列表、中部纵向四槽、右侧详情与操作；HUD使用1920×1080参考分辨率缩放，右上角四槽与按钮紧凑显示。
- 点击选择、点击操作按钮提交，无拖拽或批量保存；关闭保留已经提交的装配结果。

## 暂停与结算接入

- 通用计数管理按每个已打开窗口持有一份请求实现，重复开关幂等，关闭/注销/销毁释放自身请求；仅最后一份释放恢复原时间倍率。
- 装配、兽印三选一、增益三选一均暂停；Boss结算提示也登记暂停，避免结算操作期间继续战斗。
- Boss奖励选择完成后才弹出结算，避免结算遮挡奖励；关闭当前界面不能取消其他界面的暂停。
- 打开或关闭导致暂停状态变化的当前帧屏蔽战斗输入，避免关闭按钮点击穿透为普攻。

用户已明确确认的局内保留、自由装卸、重试清空、奖励只获取、重复转币与多界面暂停规则见[兽印装配界面](../02-系统设计/07-兽印装配界面.md)，上述内容只补充待定参数及实现选择。
