# 地图与流程暂定设计

> 状态：暂定，未获策划确认。用于搭建一条可完成的 Demo 线性关卡。

## 地图分段

| 区段 | 暂定内容 |
|---|---|
| 起点区 | 玩家出生、显示 HUD，不设置开始 UI |
| 普通战斗区 | 2 个普通敌人刷新点，每点 4-6 只 |
| 检查点区 | 精英战前设置 1 个检查点，允许玩家升级 |
| 精英区 | 1 只精英敌人，击败后打开通往 Boss 区的门 |
| Boss 房间 | 1 个独立房间，进入后封闭出口并生成 Boss |
| 结束区 | Boss 被击败后显示完成提示，提供返回和重试 |

## 暂定流程

- 2D灰盒使用朝向Z轴的正交摄像机，固定横向位置、纵向跟随玩家。暂定向前偏移3个单位，让玩家保持在视口高度35%附近，避免离开画面或被顶部HUD遮挡；镜头偏移与地图边缘构图待美术联调确认。

1. Launch完成框架初始化后进入开始界面，点击开始游戏后进入地图起点。
2. 玩家向上探索并触发普通敌人战斗。
3. 玩家可以回头，但已完成的普通战斗暂不重新生成。
4. 到达检查点后保存本次 Demo 进度，并开放暂定升级操作。
5. 击败精英敌人，弹出三选一奖励并打开门。
6. 进入 Boss 房间，触发 Boss 战。
7. 击败 Boss 后显示完成提示，玩家可以返回或重试。

## 失败与重试

- 第一次生命归零：原地或安全点复活，保留当前构筑。
- 第二次生命归零：本局失败，回到地图起点重新开始。
- 暂定不重置 Demo 配置，但每局重新生成敌人状态。

## Boss货币结算暂定规则

- 已确认 Boss 需要奖励大量货币；具体金额和用途尚未确认。
- 联调暂定每次击败 Boss 奖励 300 货币，金额由 DemoGameplayConfig 的 bossCurrencyReward 配置。
- 击败时自动结算并在 HUD 显示；同一局只发一次，不另建胜利界面或货币拾取物。
- 一次复活保留货币，重新开始本局时清零；再次击败 Boss 可以获得新一局奖励。
- 暂不接入商店、消费或局外存档。金额、获取交互和清零规则仍待策划确认。

## 普通刷新点灰盒参数

- 当前联调取每点4只，共8只普通敌人，符合暂定4–6只范围；数量尚未获策划确认。
- 两点中心分别位于2D地图XY坐标(0,8)、(0,18)，触发半径均为4；配置ID为common_wave_01、common_wave_02。
- 两点均属于普通第1波，各点接近时触发一次；完成后回头不会重新生成，重试恢复两点的敌人、生命、姿态和触发状态。
- 敌人采用场景预置对象池，启用数量必须满足配置；容量不足或引用无效时报告错误并阻止该点触发。
- 点位、半径与数量待地图节奏和正式资源联调后确认。

## 精英与 Boss 门灰盒参数

- 精英位于(0,36)，精英门位于(0,42)，初始关闭，击败精英后开放通路。门必须位于精英之后，避免玩家无法接近敌人。
- Boss 位于(0,48)，入口门位于(0,44)，初始开放。Boss 刷怪配置 boss_spawn 的触发半径暂取2，玩家越过入口进入房间后才生成 Boss 并关闭门；击败后再次开放。
- 精英遭遇使用 elite_wave_01 配置（1只、触发半径8）；Boss 遭遇使用 boss_spawn 配置（1只、触发半径2）。对象缺失或敌人类型与配置不匹配时报告错误并阻止触发。
- 重试恢复精英门关闭、Boss 入口开放和两处遭遇未触发状态。封门规则、坐标及半径仍为暂定，未获策划确认。
