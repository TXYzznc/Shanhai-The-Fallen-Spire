# 《渡山海》Demo游戏设计总览

> 状态：Demo范围已部分确认，进入详细策划补齐阶段
> 文档职责：说明Demo是什么、玩家做什么、哪些内容进入本次交付，以及哪些规则仍需甲方确认。

## 一句话概念

一款以《渡山海》世界观为背景的2D战斗类肉鸽Demo。玩家操控一名近战角色沿线性地图向上推进，利用普攻、闪避、技能、大招和兽印组合击败异兽，最终挑战Boss。

## 当前Demo范围

- 1名可操作角色。
- 1张线性地图，玩家从下往上推进，并允许回头。
- 1种普通敌人、1种精英敌人、1个Boss。
- 3个兽印。
- 四个兽印槽位：普攻、技能、大招、属性。
- 肉鸽增益选择，准确数量和具体效果仍待补齐。
- 从Launch启动，显示游戏标题、开始游戏和退出；点击开始后进入Demo游戏场景。
- PC平台。
- 不制作Demo剧情。

## Demo流程

```text
Launch启动
→ 开始界面（标题、开始游戏、退出）
→ 点击开始，进入线性地图
→ 探索并触发敌人索敌
→ 击败普通敌人
→ 击败精英敌人并获得兽印三选一
→ 经过检查点并进行升级
→ 击败Boss
→ 获得大量货币与兽印三选一
→ 结束或从头重试
```

## 当前已确认的关键规则

- WASD或手柄左摇杆移动，鼠标或手柄右摇杆控制攻击方向。
- 普攻为2段攻击，大部分攻击允许移动。
- 闪避占用1个角色格子，移动和攻击过程中均可触发，具有无敌帧（2026-10-07用户追加确认）。
- 1个主动技能：朝角色面向方向释放扇形重攻击。
- 1个大招：能量随时间缓慢恢复，满能量后由玩家主动释放。
- 受到攻击触发硬直；在限定时间内受到足够伤害会触发失衡。
- 一局有1次复活机会，复活用完后重新开始。
- 精英敌人Demo中固定掉落兽印选择，Boss固定掉落兽印选择；每次都是三选一。
- 一个波次的敌人分布在地图若干位置，进入敌人索敌范围后触发战斗。
- 击败精英敌人后开门，地图包含1个检查点。
- 增益选择展示3项，悬浮查看效果，再次点击确认；需要图标，不需要稀有度，但有等级。
- 不制作胜利和失败界面；保留返回功能。

## 不应直接视为已确认的内容

玩家基础属性、3个兽印的实际效果、普通敌人/精英敌人/Boss的行为和数值、增益条目数量与效果、失衡阈值和持续时间、地图具体布局、资源制作边界仍需详细策划确认。
