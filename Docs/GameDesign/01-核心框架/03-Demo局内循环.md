# Demo局内循环

> 状态：部分确认

## 主循环

```text
移动探索
→ 进入敌人索敌范围
→ 一波战斗
→ 获得经验、货币或兽印选择
→ 前往下一段地图
→ 到达检查点并升级
→ 击败精英敌人并获得兽印
→ 进入Boss房间
→ 击败Boss并进行最终奖励选择
→ 结束或重试
```

## 节奏要求

- 地图为单条向上推进路线，但允许回头。
- 战斗由进入索敌范围触发。
- 当前确认只有一个敌人波次；波次内敌人以群聚形式出现。
- 精英敌人被击败后开放道路。
- 地图包含一个检查点，用于升级。

## 需要继续补齐

- 地图分段数量。
- 每段普通敌人数量和刷新点。
- 精英敌人的位置和房间尺寸。
- Boss房间的进入条件、封锁方式和解除条件。
- 一局预计时长。
