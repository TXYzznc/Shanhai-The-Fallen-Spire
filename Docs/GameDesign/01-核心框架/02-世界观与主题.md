# 世界观与主题

> 状态：世界观方向已确认，Demo剧情暂不实现

## 世界背景

《渡山海》的世界以世界塔为中心，外部依次分布守护堡垒、无色池、死亡山谷、禁忌冰川和大森林。世界塔倾斜损坏后，碎片散落各地并引发灾害。

腐蚀雨事件使人和兽发生异变，出现新的头颅与攻击性行为。玩家扮演一名失去部分记忆、身上带有绷带和长剑的人，在老师的指引下前往世界塔。

## Demo使用的主题

- 场景：大森林第一层。
- 情绪：神秘、明亮、具有故乡归属感。
- 环境：森林、山丘、水池、灌木、岩石和受侵蚀的植物。
- 敌人：森林原住民受到侵蚀后发生异变。
- Demo剧情：不制作剧情演出，仅使用环境和敌人表现传达主题。
