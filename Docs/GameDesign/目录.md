## 文档维护规则

1. 总览记录稳定结论，系统文档记录具体运行规则，Demo文档记录本次交付范围。
2. 未确认的设计不填写猜测数值，统一进入开放问题。
3. 同一条规则只在一个文档中作为正式定义，其他文档使用链接引用。
4. 甲方确认需求表中的内容后，需同步更新系统文档、内容清单和验收标准。
5. 完整版规划内容不自动进入Demo范围。
