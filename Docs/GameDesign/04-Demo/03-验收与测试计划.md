# Demo验收与测试计划

> 状态：初版验收清单

以下勾选项用于完整交付验收。已完成的单项 Editor 验证、验证范围和暂定条件记录在文末增量表及开发任务表中；单项完成不代表整体验收完成。

## 流程验收

- [ ] 从Launch启动进入标题/开始游戏/退出界面，点击开始后进入游戏场景。
- [ ] 玩家可以从地图下方开始并向上推进。
- [ ] 玩家可以回头。
- [ ] 进入索敌范围后触发一波敌人战斗。
- [ ] 击败精英敌人后道路开放并出现兽印三选一。
- [ ] 到达检查点可以完成升级。
- [ ] 进入Boss房间并完成Boss战。
- [ ] Boss被击败后出现货币和兽印三选一。

## 战斗验收

- [ ] WASD和鼠标输入正常。
- [ ] 手柄左摇杆和右摇杆输入正常，若本次交付包含手柄测试。
- [ ] 普攻可以完成2段攻击。
- [ ] 移动与攻击中可闪避；无敌帧内免伤、不触发受击硬直，到期后恢复正常受伤。
- [ ] 主动技能为面向方向的扇形攻击。
- [ ] 大招能量随时间恢复并可主动释放。
- [ ] 受击触发硬直。
- [ ] 失衡触发、摔倒和额外伤害表现符合最终数值表。
- [ ] 第一次死亡后可复活，第二次死亡后重开。

## 构筑验收

- [ ] 3个兽印均能进入正确槽位。
- [ ] 四个槽位分别显示普攻、技能、大招和属性效果。
- [ ] 一个兽印不能同时占用多个槽位。
- [ ] 更换兽印后旧效果立即消失。
- [ ] 增益选择展示3项。
- [ ] 悬浮显示增益效果，再次点击完成确认。
- [ ] 增益图标正常显示，等级正常显示。

## 交付验收

- [ ] PC构建可以在目标机器启动。
- [ ] 无缺失的本地包和资源依赖。
- [ ] FastScriptReload子模块已初始化。
- [ ] 交付版本不依赖开发者本机绝对路径。
