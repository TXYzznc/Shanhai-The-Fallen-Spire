# Demo版本目标与范围

> 状态：Demo范围部分冻结，详细规则待补齐

## 目标

验证“角色战斗 + 兽印构筑 + 肉鸽增益 + 线性推进 + Boss战”的最小可玩闭环。

## 必须包含

- 1名玩家角色。
- 1张向上推进的线性地图。
- 1种普通敌人。
- 1种精英敌人。
- 1个Boss。
- 3个兽印。
- 普攻、闪避、1个主动技能和1个大招。
- 增益三选一。
- 1个检查点升级。
- 精英和Boss的兽印掉落选择。
- 1次复活与死亡重开。
- PC运行和可验收打包。
- Launch开始界面（标题、开始游戏、退出），UI/Item和动态实体预制体，可替换2D攻击/粒子/飘字/受击闪烁。
- 本局已拥有兽印列表与自由装配界面、HUD右上角四槽状态、HUD按钮和Tab入口；兽印奖励获取与装配分离，重复选择兑换货币。
- 通用界面暂停管理，装配与三选一奖励打开时暂停，所有暂停请求释放后继续。

## 不包含

- Demo剧情和CG。
- 商店、通用物品背包、NPC和图鉴。本局已拥有兽印列表包含在兽印装配范围中。
- 多角色、多地图、多Boss。
- 完整局外成长。
- 未确认的额外敌人种类和复杂事件。

## 目标平台

PC。输入优先支持键鼠，手柄输入作为已确认的兼容方向。
