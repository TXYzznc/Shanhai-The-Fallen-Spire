# 兽印装配与暂停验收

> 本批源代码及预制体已经接入，20项自动测试通过（包括奖励卡实际射线悬停回归）。本文件是用户实机步骤，不代表实机已通过。现有旧Windows Player尚未包含本批更新，需要后续重新出包后验收；不能沿用旧包结论。

后续HUD拆分同样保持以下操作：奖励、装配、结算是GF.UI独立窗口，加载请求立即暂停。拆分后27项自动测试通过，增加加载失败/取消/复用、退出重入、显示内容及Boss结算顺序验证；实机与重新出包仍未执行。

1. 从Launch进入开始界面，再开始本局。确认右上角普攻、技能、大招、属性四槽初始为空，并有“兽印装配 [Tab]”按钮。
2. 点击按钮或按Tab打开装配，确认空列表提示与四槽显示。此时移动、攻击、闪避、敌人行动及冷却全部暂停，但界面仍可操作。Tab、Esc或关闭按钮均能关闭并恢复战斗。
3. 击败精英触发兽印三选一。确认战斗暂停、奖励卡有兽印图标、界面没有目标槽按钮。选择一个未拥有兽印并确认，右上角装备仍为空，获得提示说明按Tab装配。
4. 打开装配界面，选择已拥有兽印和目标槽位，预览效果后点击装配。确认对应槽位和HUD显示同一兽印图标，实际战斗效果与所选槽对应。
5. 将已装配兽印移动到另一槽，确认原槽变空，目标槽更新，同一个兽印仅占一槽。卸下后四槽对应位置变空，兽印仍在已拥有列表可重新装配。
6. 获得第二个兽印后装入已有兽印的槽，确认旧兽印仍在列表，旧效果移除，新效果生效。
7. 再次获得兽印奖励时选择“已拥有，兑换100货币”的选项，确认货币只增加一次，已拥有列表没有重复副本，装备不改变。100为可配置暂定值。
8. 到达检查点打开增益三选一，确认战斗同样暂停；选择增益后按原规则生效并恢复战斗。在奖励或结算显示期间，装配按钮与Tab不能打开装配界面。
9. 首次死亡复活后确认拥有列表与装备保留；重试后拥有列表、装备、货币和界面状态清空，游戏不会留下暂停。
10. Boss兽印奖励先显示，确认奖励完成后再显示结算。结算可暂停，关闭结算只释放自身请求。

多个暂停界面、重复开关、禁用/销毁释放、语义输入与时间倍率恢复由自动测试覆盖；通用管理器要求所有登记的暂停请求均释放后才恢复。
