## ADDED Requirements

### Requirement: 专业窗口在派发边界内高自治
专业窗口 MUST 在已派发工作、可写路径、已确认方案和验收边界内自主讨论、实施、验证和增量归档。职责内的用户决定 MUST 由提问窗口记录并直接同步受影响窗口。普通进度、单项决定、测试通过、增量归档和独立提交 MUST NOT 通知制作人。

#### Scenario: 职责内用户决定影响另一个窗口
- **WHEN** 专业窗口获得会影响另一个职能的用户决定
- **THEN** 提问窗口 MUST 直接通知受影响窗口，而不经制作人转述

### Requirement: 制作人只接收强制升级与批次验收
制作人 MUST 只处理范围、优先级、负责人、排期、OpenSpec边界或依赖变化；点对点无法解决的冲突；共享资源或仓库异常；新授权；S0/S1暂停；以及整个派发批次完成。除这些事件外，窗口 MUST NOT 发送仅供知悉的制作人消息。

#### Scenario: 普通独立提交完成
- **WHEN** Git 集成窗口完成一个专业窗口的独立提交
- **THEN** 它 MUST 仅向请求窗口回传结果，且不得通知制作人
