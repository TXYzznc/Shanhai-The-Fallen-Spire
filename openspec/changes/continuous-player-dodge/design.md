# 连续闪避

TryDodge只初始化方向、剩余时长、速度及既有取消/无敌/冷却状态，不立即位移。Update先消费同一输入快照触发闪避，再按min(deltaTime,剩余时长)推进；速度为距离/时长，不叠加普通移动和转向。

复用Rigidbody2D.Cast与缓存命中数组，每一步检查碰撞和边界，实际距离不足即结束，障碍移除后不恢复。暂停沿用GamePauseController及时钟，重试、受击硬直/死亡和OnDisable清除进度。不引入每帧分配、设备读取或脚本执行顺序依赖。

配置距离2米、时长0.2秒；非正时长保护为至少0.01秒。保留攻击系统既有取消与同帧优先级，不改变伤害结算。
