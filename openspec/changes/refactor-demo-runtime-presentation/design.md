## Context

Unity2022.3、GF_X、2D XY。三轮用户决定见decisions.md。当前UI的BuildView和场景实体不能仅另存为Prefab后继续旧方式。

## Goals / Non-Goals

目标：可编辑的真实预制体、Launch菜单入口、动态实体与对称生命周期、事件驱动的2D反馈，完整流程回归。
边界：不改变攻击结算/数值，不新增远程玩法、设置/存档或局外系统；临时资源可替换，其他暂定设计仍待确认。

## Decisions

| 候选 | 优点 | 代价与结论 |
|---|---|---|
| 场景预制体实例 | 编辑简单、引用直观 | 不满足运行时动态生成与回收，排除 |
| 项目自行Instantiate/Destroy注册表 | 迁移局部简单 | 重复GF资源加载、UI/实体池及场景清理，维护两套生命周期，排除 |
| GF_X UIComponent/EntityComponent＋项目薄适配层 | 沿用资源路径、异步创建、实体/UI池和退出清理 | 需要明确初始化/取消/回收绑定；选用，不改框架核心 |

- 菜单在框架准备后开启；开始按钮只发一次进入请求，加载期间防重入，失败可重试。退出使用正常应用退出路径。
- UI预制体含编辑器可见节点及引用；UIForm适配绑定本局上下文，关闭时解除监听与清空对象引用。复用卡片、槽位、按钮、飘字为Item预制体。
- 实体Prefab仅引用配置和内部组件；禁止保存对场景Player/Input/HUD/Camera的外部引用。生成后显式注入输入、目标、关卡和表现服务。
- 玩家在进入本局后创建；敌人按刷新/遭遇触发创建。加载期间取消、死亡回收、重试、退出和重进由会话持有句柄，防旧异步回调污染新局。
- 首次复活沿用现有规则；二次死亡与重试清空构筑/货币/快照，重建或回收后重置实体，不残留旧敌人、监听、粒子、飘字。
- 表现只消费成功动作及有效伤害结果；飘字显示实际结算值，避免从生命差倒推复活/治疗。拒绝伤害和冷却拒绝动作不产生反馈。
- 粒子/斩击与飘字有有界池和寿命，XY表现、排序明确；受击闪烁与现有失衡/死亡状态协作，回收时取消显示和复位颜色。
- 程序与GF适配的程序集依赖保持单向；迁移前核对Hotfix、Demo和Editor依赖，避免循环。

## Risks / Trade-offs

动态对象导致旧场景引用及QA查找失效，需迁移绑定和探针。GF对象复用要重置Awake以外的运行状态。资源包必须包含新Prefab，菜单PlayMode与Launch完整入口分别验证。编辑器生成器只负责创建设计资产，运行时禁止BuildView式拼建。

## Migration Plan

先登记新增任务/更新旧启动约定；保存并核对现有UI/实体模板；接入菜单和UIPrefab；迁移动态实体/波次；接表现；完成Launch、重试、退出/重进与资源构建回归。每阶段保留原证据，不提前标DoD完成。
